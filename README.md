### 💡 Why this repository exists
Data scientists, AI researchers, and machine learning engineers frequently hit Google Colab usage limits (`Usage limits exceeded`), runtime timeouts, or GPU disconnections.
This repository maintains an **autonomous daily verification engine** tracking all legitimate, verified platforms offering free GPU (T4, P100, A10G, TPU v2-v4), high-RAM instances, and persistent JupyterLab / VS Code web environments without surprise credit-card charges.

## 🤖 How the Autonomous Verification Engine Works
This repository is maintained automatically by a background verification daemon:
1. Every 24 hours, an automated runner sends latency probes and handshake pings to each platform's interactive console endpoint.
2. Platforms with discontinued free tiers or modified quotas are automatically flagged and updated.
3. Live badges and latency benchmarks (`ms`) are re-computed and committed directly to `main` via GitHub Actions.
